# Puzzle Paradise Visual Style Guide

## Color Palette
- Primary: #2563eb (Royal Blue)
- Secondary: #1e293b (Dark Slate)
- Background: #f4f6f8 (Slate 100)
- Card: #ffffff (White)
- Border: #cbd5e1 (Slate 200)
- Text Primary: #1e293b (Dark Slate 900)
- Text Secondary: #64748b (Slate 400)
- Accent Success: #059669 (Emerald 600)
- Accent Warning: #d97706 (Amber 500)
- Cell Background: #e2e8f0 (Slate 100)

## Typography
- Font Family: -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif
- Base Font Size: 14px
- Heading Font Size: 15px (600 weight)

## Spacing System
- Unit: 4px
- Card Padding: 12px
- Grid Gap: 4px-6px
- Cell Size: 50px (default), adjustable per game

## Component Styles
- Buttons: bg-primary, white text, rounded 6px, transition 0.2s
- Active state: border-bottom primary color 3px
- Grid backgrounds: #e2e8f0 or #334155 (dark mode)
- Cell borders: 1px solid #cbd5e1
- Cell selected: #e0e7ff (Border 200 with slight blue tint)

## Responsive
- Max width: 450px
- Grid layout: responsive, auto-adjusting
- Touch-friendly: minimum 44px hit areas
